SYSTEM ARCHITECTURE & ENGINEERING SPECIFICATION

SkyFlow Ops — Dual-Engine Platform Architecture

Production-grade dual-engine architecture designed for atomic seat inventory protection, cryptographic human approval boundaries, and AI vector policy querying.

1 Authoritative REST Writer Layer
FastAPI (Python 3.11)

Sole transactional entrypoint for all inventory mutations. Enforces Pydantic input validation, CORS verification, connection pooling, and structured HTTP error contracts.

2 Database Ledger & Concurrency Protection
Supabase PostgreSQL 17.6

Prevents double-booking via SELECT ... FOR UPDATE row-level locks, unique idempotency keys, and PL/pgSQL trigger validate_flight_capacity_sum for total aircraft seat validation.

3 Vector Policy RAG Workbench
Pinecone Serverless + MiniLM Embeddings

Indexes policy documents into 384-dimensional dense vector embeddings. Provides grounded policy citations for cancellations and baggage rules with zero hallucination.

4 Cryptographic HITL Approval Boundary
HMAC-SHA256 Token Security

High-value refunds (> $500) generate cryptographically signed HMAC approval tokens with 1-hour expiration, cross-resource booking ID matching, and tamper protection.

5 Asynchronous Workflow & Agent Orchestrator
n8n Cloud / Docker Engine

Processes background waitlist promotions, email notifications via Gmail OAuth2, and scheduled refund workflow triggers via secure API callbacks.
